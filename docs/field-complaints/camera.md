# Field complaints: camera and lighting (webcam and camera-as-webcam)

Date: 2026-11-05. Scope: camera and lighting only.

## Method and honesty notes

- Searched via a web search tool. Reddit itself was not directly reachable; the search surfaced OBS forum, Elgato, Logitech, Canon, Dell, Zoom and Microsoft threads, plus a few Reddit mirrors and blog posts. Reddit-specific wording (r/Twitch, r/letsplay, r/Cameras) is therefore thin: **no r/Twitch/r/letsplay/r/Cameras thread was read directly**. Treat "how often it comes up" as an estimate from how many forum threads exist per topic, not a count.
- "Accepted fix" means the fix the thread or vendor page converged on. Many OBS forum threads end with no confirmed solution; those are marked "unconfirmed".
- Blog/SEO pages (evezone, ceedo, alibaba, ulanzi etc.) are weak sources and are marked (blog).
- "In Setup Coach today?" was checked by grep in `core/src/video/findings.rs`, `core/src/system/ids.rs`, `core/src/system/camera.rs`, `core/src/video/recommend.rs`, `profiles/*.json`. Finding ids quoted as in code.
- Not covered (no time): YouTube/Twitter threads, Sony/DJI support forums, Elgato HD60 specific settings, colour-science of skin tones, RGB light colour casts (only generic).

## Ranked list: 10 biggest gaps to build next

Ranking = (how often forum threads appear) x (how fixable by software) x (not yet covered).

1. **Who is holding the camera (rows 1, 21, 25).** Replace generic `camera.no_video` text with a named culprit: Teams, Zoom, Discord, browser, Camera Hub, Logi Tune, EOS Utility, other OBS scene/Virtual Camera; offer "close it for me" or the Multi-App Camera toggle. Highest volume of OBS threads; the app already detects the setting but not the holder.
2. **USB topology and link health (rows 4, 5, 6, 26).** Read per-device link speed (USB 2 vs 3), which xHCI controller each camera/capture card sits on, and USB selective-suspend; detect two heavy video devices on one controller and tell the user which port to move to. Today only generic advice after dropouts.
3. **Disappear/reappear watcher (row 26, 5).** Track device removal/arrival and stream-stall events (PnP notifications), and tell "flaky cable/port" from "overheat" by timing pattern. Needed to make `camera.dropouts` actionable.
4. **Capture-card / HDMI chain doctor (rows 19, 20).** Detect "no signal" vs black, static overlays (REC dot, focus boxes, menu icons) from frame statistics, wrong camera HDMI mode; coach the camera menu changes (info display off, auto power-off off, LCD sleep, NTSC 60p).
5. **Camera body as webcam: detect "body present, not a webcam" (row 21).** Use VID/PID of known bodies already in profiles; check vendor utility installed, conflicting processes (EOS Utility/launcher), Wi-Fi/Bluetooth warning, cable/port, USB mode question.
6. **Overheat / runtime-limit handling (row 22).** Turn the profile `Overheating` quirk into a live feature: record time-to-stall per body, prompt dummy battery/mains, 720p, HDMI instead of USB streaming, auto power-off off; warn before the limit during a stream.
7. **Lip-sync measurement and fix (row 23).** Read OBS mic sync offset, run a clap/beep test (mic transient vs frame motion), suggest or set offset; check 44.1/48 kHz mismatch for drift. Currently text only.
8. **Recording-side colour/range check (row 24).** Compare OBS output colour space/range with source; explain "only washed out in player X". Partly present for the camera side.
9. **Virtual camera / phone-as-camera diagnosis (row 25).** Virtual camera started? Camo/DroidCam connected? Browser holding it? Class exists, no specific findings. Frequency unverified.
10. **Persistent camera-setting guard visible to user (row 17).** Findings exist for overrides; add a visible "settings were reset by X, restored" event and per-vendor guidance (G HUB + Options+/Logi Tune double-management, Teams auto-adjust controls, Zoom). Lower gap since detection exists.

## Open points

- "5000-5600 K" key-light advice, `Overheating` durations (about 27-30 min) and PCIe Gen3 workaround for AMD boards come from single sources (blog, one forum post, Elgato page respectively); only the Elgato page is vendor-primary.
- Not researched: Sony Imaging Edge Webcam fights, DJI Osmo/Action webcam mode, Elgato HD60 specifics, RGB-light colour-cast frequency, skin-tone accuracy.
